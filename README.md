# Visit China AI · Arrival Workspace

A personal conversation-led Shanghai arrival-support prototype: incremental trip requirements, source-backed field guides, power/connectivity recovery, a pre-arrival email draft and an operations console.

## Current repository status

**The complete V3 application is in the downloadable source ZIP attached to the project ChatGPT conversation, not yet as ordinary application files in this repository.** The earlier V2 source transport failed its part-8 SHA256 check. The recovery workflow also failed; verification was not bypassed. Do not treat this repository or its failed workflows as a deployed or tested website.

Read [V3_HANDOFF.md](V3_HANDOFF.md) for the source archive hash, implemented features, measured development checks, and instructions for a reviewed normal Git upload from the complete source directory.

The downloadable V3 runs with Node.js 22+ or as a compiled browser-local HTML demonstration. Optional DeepSeek and Amap adapters are server-side and explicitly opt-in. No real provider credentials or external model call, OTA booking inventory, charging operator, microphone or Vercel live site has been validated. A listed point of interest is not verified inventory; a user-reported reservation is not an imported booking.

No provider keys, private internship materials or customer data are included here. A public cloud frontend cannot automatically access a user's localhost.
