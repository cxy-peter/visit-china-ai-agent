# Visit China AI V6.3

2026-09-25 · 个人项目，AI辅助实现。

## 这次改动

- 浏览器在线识别成为唯一语音入口，页面不再加载 Vosk 模型或 LiveKit 客户端。旧实现保留在源码历史与兼容测试中。
- 播报期间停止识别，结束约 0.7 秒后自动续听，减少助手录入自己声音的问题。可点击“打断并说话”。完整句默认等待约 3.2 秒；未完句保留草稿。浏览器识别服务自动结束时保留片段，修复只有临时识别结果时不提交的问题。
- 模型查询过程中输入不会取消原查询。原答案留在原来的消息，新增细节等待该轮完成后结合上下文处理；尚未发送的草稿不会被读出。多个追加片段显示合并处理状态。新聊天、重置、撤销授权仍取消旧请求。这不是向同一个模型请求的内部推理过程插入文字。
- 对话设置提供“管理员登录并连接 DeepSeek”，使用 Operations 的管理员账号与密码，省去跳转后台再返回连接的步骤。体验码和服务端 API Key 继续明确区分；密码不写入聊天存储。
- 左侧显示本地聊天标题与最近需求摘要，可以新建、恢复、删除。默认保存最多 40 个聊天，每个保留最近 30 轮；仅限当前浏览器，不是账号跨设备同步。
- 由 DeepSeek 拆分最多 6 个独立需求，按 1、2、3 分项展示答案、资料和工具。上海火车站的充电宝查询与去杭州的铁路需求可并存；多个行程的修改、导出按各自卡片定位。
- 将“已公布支持范围／个人使用条件／明确不支持／没有证据”写入通用回答规则，覆盖银行卡、地铁票、酒店、寄存、充电等服务。个人未提供余额、证件或其他条件，不得直接推出服务不支持。来源、数值、语言和过期检查继续保留。已知分块引用归并到其父文档，未知引用仍拒绝。意图结构不合法时由模型修正一次，仍执行同样的字段和类型校验，超过一次则停止。

## 资料覆盖

上海 16 区均有中英文基础行程卡及 Markdown、CSV、JSON 导出：浦东、黄浦、静安、徐汇、长宁、普陀、虹口、杨浦、宝山、闵行、嘉定、金山、松江、青浦、奉贤、崇明。新增各区采用两个有官方公开记录的地点，时间是可调整的规划分配，不是实时路程或营业时间。原长宁及抗战纪念地较完整的吃住记录保留；其余区尚未核对的餐馆和酒店明确留空，没有把其他区商户冒充附近推荐。

- [上海市政府公开旅游地点记录，2025-04-27](https://english.shanghai.gov.cn/en-CityTour/20250427/b2eff944fe05497ea6424937b170b84c.html)：用于地点发现，不复用已结束的节庆活动。
- [上观新闻的沪杭车票观察，澎湃转载，2024-06-05](https://www.thepaper.cn/newsDetail_forward_27629921)：收录对应 2024-06-15 的 6 条历史列车记录，可按席别、价格、时段比较。未知一等座票价、到达时刻保持未知。不是实时票价、时刻表或余票接口。
- [上海机场集团 2025 夏秋航季记录](https://www.shairport.com/xwg/info_itemid_41482.html)：展示浦东、虹桥的历史航线规划及官方查询入口，不生成虚构航班或当前价格。
- [上海市交通委机场联络线开通公告](https://jtw.sh.gov.cn/xwfb2/20241226/a5c8290243d047b7b8d0d078e332708f.html)：保留开通时费用、时间范围，明确是历史记录。

## 验证口径

- 本地程序／接口 351 项通过。
- 原有 7 组浏览器回归 168 项通过；V6.3 新交互测试 32 项通过（合计 200 项浏览器检查），结果见 `evidence/v6.3/browser/V6_3_界面验收.json`。
- 新语音检查使用合成识别事件，验证实际页面控制器、停顿合并、播报暂停收音、结束续听和临时结果提交。未测真人麦克风、口音、扬声器距离和浏览器在线识别服务稳定性。
- 真实 DeepSeek 以管理员会话调用，测试记录单独保存。首轮机场问题发生 `ANSWER_SOURCE`，保留失败记录；修复后 8 轮真实问题、32 项检查通过，含充电宝与高铁双需求、中英文银行卡、杨浦/青浦/崇明路线、席别比较和机场资料。另一次正式站浏览器变式触发意图结构错误，补上一次有界格式修正，并保留该失败记录。候选 8 轮完整响应约 7.5–41.6 秒，属于小样本而非 SLA；不把失败隐藏成首次全通过。
- 本轮未重跑 20,000 条全语料 Loop，不将历史语料成绩算成本轮模型识别率；旧评测、来源停用、运营审核和回滚机制保留。

## 使用

1. 刷新正式站，打开对话输入框旁的设置。
2. 选择“管理员登录并连接 DeepSeek”，输入 Operations 管理员密码；也可用已有 VC- 开头体验码。sk- 开头密钥只在服务端配置。
3. 开始通话并授权麦克风。助手播报后自动恢复收音；模型查询期间可继续补充，播报途中请点打断按钮。
4. 可试“上海火车站哪里查充电宝？另外怎么坐高铁去杭州，二等座便宜一点”，观察分项答案与历史价格表。
5. 可试“杨浦区十点出发的一天路线”，或把杨浦替换成任一上海区名，再导出行程。

浏览器不支持在线语音或服务暂时不可用时仍可文字输入。新方案优先防止回声，因此不宣称浏览器扬声器环境下的自动全双工打断。库存、最新报价、实际步行时间和真人收音质量仍需另行验证。
