## 现在怎样进入 DeepSeek

在“聊天设置”输入管理员签发的 `VC-…` 体验码，或导入该文件。`sk-…` 是 DeepSeek 平台 API Key，只供服务端使用；网页误填会在发送前拦下并清空。已经从正式网页验证新体验码 → 真实 DeepSeek → 地铁路线 → 多轮酒店问题。体验码支持期限与额度。Operations可自行签发、设置额度和期限、撤销；后台不保留完整码。

## 本版交付

- 对话自动检索共享资料；Source Library 的手动“带入对话”按钮已移除。证据分大于60、地区与版本有效的正文可进入回答，60及以下待核验。
- 问题反馈可选择分享最多8轮相关上下文，支持预览脱敏及撤回；后台按意图、事实、时效、路线、细节、流程、语言、连接和其他九类定位。DeepSeek总结为待核对假设；管理员可补资料、编辑技能候选、自动验收、回放、发布或回滚。
- 运营大表列出解决反馈、CSAT、推荐点击漏斗、检索与执行质量、工单过程的事件、分子分母和时间范围。没有订单回执、退出定义或情绪标签的指标显示未接入，不编造GMV或转化提升。
- 收录20条真实酒店、餐饮、交通便民服务记录，其中10条有公开电话，关联车站和地址。地图与运营方入口可继续查证；未接实时房态、余票、价格、柜机库存或支付接口。
- 新增TenPayGo别名检索、Nihao China及便民新闻。每72小时到期轮转检查来源和发现新闻候选，也可手动更新。新标题不直接成为事实；不能把TenPayGo推定为已经接入上海地铁闸机。
- 保留轻量执行图、地铁路网关系、Harness与反馈Loop。历史客服仓库确有Neo4j实现；本站未部署Neo4j，也未进行DeepSeek权重训练。检索为BM25、稀疏TF-IDF、RRF及确定性重排。
