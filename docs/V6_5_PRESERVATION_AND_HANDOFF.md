# V6.5｜原提示词保留与接续说明

核对基线：已合并V6.4 main `23872e914aa4c54df09762ead2ce29ec81078c83`。项目名称始终为Visit China AI；五城是北京、上海、广州、深圳、香港，覆盖深度不同。

## 1. 保留的是哪些能力

- `v5/model-intent.js`原有意图提示词作为连续完整文本保留，只前置五城归一和香港适用范围补充；没有删除原有多任务、否定、地点、资格与证据规则。
- `v5/assistant.js`生成提示词、`v5/server.js`的EXTRACT与IMPROVE提示词原文保留；三份既有导出提示词保持不变。
- 原有DeepSeek请求适配器、Auto/Flash/Pro路由、输出Token预算、超时、浏览器语音、五账号工作流审核和旧展示评分模块均有逐文件兼容检查。
- 标准KB仅截获已登记的完整标准问题。追加其他需求、非标准问句或来源失效都退出快路径，继续现有处理，不使用固定答案替代所有模型能力。
- 多查询只复用原有模型返回的检索短语；保留原问，拒绝明显改变城市、渠道、数值或否定条件的提示，不额外发起三次模型生成。

## 2. 怎样证明，而不是只说“没有降级”

`tools/verify-v65-preservation.cjs`从Git基线读原文件，对模板提示词及关键模块计算SHA-256并比较；同时通过受控调用核对Flash/Pro的系统指令、模型映射、Token和超时参数。结果写入`evidence/v6.5/prompt-preservation.json`，CI遇到不符就失败。

这组检查与`npm test`、历史20,000条合成回归、五城KB浏览器检查及V6.4交互兼容检查一起运行。原有测试没有因为升级而删除。测试报告在对应GitHub Actions的`v65-validation-evidence`工件中；源码工件为`v65-verified-source`。

提示词相同不等于所有真实模型输出一定相同。新增的检索上下文和候选过滤可能改变输出，因此仍需新的人工标注语义评价。这里证明的是原文、路由、预算和开发契约被保留，不是宣称模型零退化、实时语音达标或商业收益已成立。

## 3. “模型更新”的准确含义

本次没有训练或微调DeepSeek权重，也没有调整外部账号额度。改动发生在应用层：版本绑定KB、受限多查询、五城资料过滤、候选资格与运营轨迹。复杂请求仍由原有模型处理；已批准的标准问题才免生成。

KB直出不能绕过来源检查。新来源、编辑内容、修改复核日或重新发布，都会改变源指纹并要求重新核对。反之，用户只是普通偏好交流时，不应被当成政策事实问题一律拦截。

## 4. 本地更新，不覆盖私人配置

在旧服务终端按Ctrl+C。先保存自己未提交的改动以及私有`.env`、`data/runtime`和账号文件，再将代码更新到通过CI的主分支版本。不要使用`git reset --hard`或删除整个项目目录来更新。

```bash
git status
git pull --ff-only origin main
npm ci
npm test
npm run build
npm start
```

如果`git pull --ff-only`提示有分叉或本地修改，应先解决冲突，不强行覆盖。对解压包用户，保留原目录和私有配置，用新目录安装验证后再切换。本机地址按终端输出打开；根启动入口仍为`v5/server.js`。

数据库、密钥、体验码和部署环境变量不包含在源码包里。仅存在旧进程内存的Key在重启后要由拥有者重新配置；不要在聊天、PR或公开文件中粘贴密钥。

## 5. GitHub和线上不是同一个状态

代码经过PR和CI后合并，才视为主分支更新。Vercel自动部署是否成功、部署指向哪个提交、是否存在有效私有环境变量，均应另行检查。访问页面成功也不能证明真实模型回答已验收。

当前工作没有新的付费DeepSeek或真人麦克风成绩。V6.4的历史真实模型证据仍保留，但不能改名为V6.5成绩。

## 6. 后续最小验收

1. 无Key时，五城登记的标准问题可返回有来源的KB摘要；陌生问句不会假装KB命中。
2. 同一标准问加一个签证或退款需求，应该退出直出；来源停用后不能继续使用旧标准答案。
3. 香港请求不引用只适用于内地的票务或支付规则；未知城市不变成上海。
4. 复杂多需求仍走原模型与工具；语音、文字、点选共享状态。
5. 运营能定位本次KB、改写或候选门禁轨迹；关闭排查工单不改变原用户反馈。
6. 管理员选择发布前核对源码、知识与评测指纹；不自动激活历史Loop候选。

下一阶段优先新标注问法与真实模型小样本抽检，再考虑更广的KB编辑器、学习型检索和真实人工服务。具体实现见[V6.5完整技术手册](V6_5_TECHNICAL_GUIDE.md)。
