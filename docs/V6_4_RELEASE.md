# Visit China AI V6.4

2026-09-25 · 个人项目，AI 辅助实现。

## 用户可见的变化

- 开场只显示“有什么我可以帮您？”，下面有 20 个中英文可点问题。点击提交真实问题，不自动代入虚构对话。
- 回答体验与解决反馈合成一次“有帮助 · 已解决 / 还没解决”。未解决可继续标记原因，按用户选择附上已脱敏上下文进入排查工单。旧版独立 CSAT 只作为历史指标保留，不把解决率冒充满意度。
- “上海火车站周围有充电宝吗”不会再自动生成铁路行程。车站是地点；只有明确提出乘车、买票或跨城出行时才创建铁路需求。多需求仍由 DeepSeek 分项处理。
- 机场到达问法保留已给起终点，以正文说明交通、站内指示、行李、安检和后续乘车准备；明确要求地铁路线时仍显示双语地铁图。
- 沪杭历史真实车次支持席别、便宜优先、时段、最早与最晚出发时间筛选。仍明确标注 2024-06-15 历史记录，未知字段留空；上海站与上海虹桥站不互换。
- 根据实际问题显示 Trip.com 酒店、租车、接送、列车、机票、上海英文一日团示例及大众点评餐饮入口。充电、寄存、银行卡支持咨询不会被强行添加购票推荐。没有接入实时库存或支付回执。
- 附近内容下展示近期官方活动，包含日期、地址和预约限制。过期活动按上海日期隐藏；“官方英文介绍”不等于保证现场英语服务。

## 知识与答案处理

服务资格采用通用规则：区分已公布能力、个人使用条件、明确排除条件和证据缺口。未说明额度、余额或卡设置，不得反推品牌或服务不支持。

AMEX 应按渠道回答：[Trip.com 付款说明](https://www.trip.com/ask/questions/trip.com-payment-methods.html)列有 American Express；具体订单仍以付款页与发卡行授权为准。这不能证明 12306 直接支持 AMEX。用于对照的[北京市政府 2021 年英文渠道指南](https://german.beijing.gov.cn/travellinginbeijing/quickguideontravelservices/forforeignersstayinginchina/202108/t20210818_2471118.html)只作为历史范围证据，未列出不能解释成所有渠道禁止。上海地铁拍卡另按[上海官方现行乘车指南](https://english.shanghai.gov.cn/en-Individuals-Transportation-PublicTransport/20260813/f257d5c373db4da3a8bde717b9f46b27.html)处理，不能把铁路购票、地铁闸机和钱包绑卡混为一谈。

保持原有 RAG 分块、BM25、稀疏 TF-IDF、RRF 与父文档分散排序。DeepSeek 负责意图、查询改写与有证据的文字组织；确定性工具保留路线拓扑和车费计算。无需新增 Milvus 才能修复这些分流错误，本版也没有声称接入学习式 embedding/reranker。

新知识补充路径：模型查询 → 已索引或每日发现的可信 URL → robots 与域名限制 → 有限正文读取 → 模型自评与逐字引文核对 → 符合条件者进入资料库。每次回答最多读取一篇候选。自评达到 60 才可能进入正文；无正文、冲突、过期、提示注入或活动日期不可信仍拦下。分数不是事实正确概率。尚未接通无边界搜索引擎；模型不能任意访问 URL。

公开 Reddit 经验保留社区标记和日期，只补充操作体验，不建立政策、价格或库存事实。本次没有抓取 X、Rednote 登录内容。四篇主题来源保存在 `tools/community-question-seeds.cjs`。

答案采用公开的规则评分比较引用、直接回答、端点、行动与长度。可用时比较模型与工具，选择或合并；无法比较时明确显示“未参与”。付款等服务咨询不让不相干的路线追问覆盖模型答案。它不是独立正确性裁判，也不读取模型的私人推理过程。

## 活动与运营

- 每日 06:00 UTC 检查上海官方活动和新消息列表，每轮最多评估两篇新正文；原有精选资料保持三天复核。后台提供手动更新，已有正文的 URL 去重。
- 已实际读取两个列表，发现 11 个去重候选；抓取记录在 `evidence/v6.4/event-feed-check.json`。定时任务配置和生产 `CRON_SECRET` 已确认，后续定时成功率需继续观察。
- 首批活动为[小吃嘉年华](https://english.shanghai.gov.cn/en-Events/20260918/34a075bf3cb74b0eadcffdbca9ddb7c8.html)、[世界设计之都大会展览](https://english.shanghai.gov.cn/en-Events/20260924/7782fae8d4974b249e6f085654bc403c.html)、[上海国际光影节](https://en.shio.gov.cn/TrueCMS/shxwbgs/newss/content/20260908201822130.html)。不同日期、预约、场地与现场语言边界分别保存。
- 达到 30 个样本后，越过参考阈值的指标标红。数据缺失与低样本不冒充异常。展示分母、采集事件与窗口；平台外跳仍不是订单转化。
- 重试抓取、隐藏过期活动可以自动进行。意图、技能、收费规则与流程的重要修改只生成候选，保留人工验收、发布和回滚。Loop 不自动修改模型权重。

## 评测与真实验证

- 新增 5,000 个不同问法：50 个主题，其中 17 个主题参考 4 篇公开社区讨论、33 个来自官方服务场景；含中英文、限定条件与解决要求。与旧 20,000 条无完全相同文本。不是 5,000 条真实用户日志，也不是 5,000 个独立意图。
- 完整离线检索：目标资料召回 4,485/5,000；全部结果只使用有效证据。515 条目标召回失败保留在明细中，不抹除。家族划分 4,000 开发 / 1,000 留出；查看结果后不再声称未来盲测。答案正确率与线上意图准确率须另行标注。
- 最终 Loop 使用未使用过的序号段 `[48000,60000)`，12,000 条全部跑完：目标召回 11,482 → 11,657，改善 175、退化 0；旧 20,000 条回归通过。保留 343 条未命中与完整压缩明细。候选未发布，线上资料/技能/评测代码不一致时继续阻止旧候选直接上线。
- 本地程序与接口检查 372 项；浏览器检查共 221 项：旧功能 169、语音/多需求 33、新交互 19。浏览器语音测试使用模拟识别事件，不等于真人麦克风测试。
- 初次真实 DeepSeek 测试暴露英文意图格式失败和付款答案被路线工具覆盖。修复后，中英文 AMEX、近期活动三项均通过真实模型复验，管理员登录与连接正常。初次失败记录和复验分别保留，完整回答耗时见报告，不宣称首字低于三秒。

## 保留的边界

浏览器在线语音是唯一入口。播报时暂停识别以避免收录自身声音，结束后自动续听；目前点按打断，不是可靠全双工。查询时新增输入排队补充到后续模型请求，不是直接插入正在运行请求的内部思考链。

16 区基础路线、二战主题路线、原有管理员认证、体验码、上下文归档、多需求隔离与引用校验均保留。资料库约 5,000 条官方 URL 是索引覆盖，不等于全部正文都已读过；当前饭店酒店为有出处的公开记录，车票和柜机仍无实时库存。

发布文件只包含代码、公开资料、合成问法和脱敏验收。密码、API Key、体验码、登录 Cookie、真实访客对话与用户附图不进入仓库。

## 正式站验收补修

正式站首次验收中，机场到达指引被数字校验拦下（ANSWER_NUMBER），记录保留在 `evidence/v6.4/production-initial.json`。生成现在接收逐来源的数字清单，禁止凭空加入建议缓冲时间；若仍产生无出处数字，仅进行一次针对性修正并再次完整校验，反复编造仍拦截。修正调用的 token 一并记账，多需求中的单项失败不会吞掉其他已完成答案。该补修不改变检索算法、官方索引或已有 Loop 评测结论。

进一步实测发现模型返回“上海”而资料库使用“Shanghai”，导致已召回正文被城市范围过滤。意图入口现在统一中英文城市名（上海、北京、中国），保留车站端点和未识别城市，避免把有证据误判为无资料。数字修正前后和城市名问题的实测记录分别保留。
