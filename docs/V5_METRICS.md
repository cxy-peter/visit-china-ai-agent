# V5 指标及验收口径

本机 /api/v5/metrics 统计当前进程中记录的call_started、input_committed、model_proposal、model_proposal_confirmed、feedback、call_ended等事件；另外展示持久反馈与候选发布记录。现有事件不是独立旅客、PSTN通话或真实业务订单。

| 指标 | 应采用的分母/来源 | 当前状态 |
|---|---|---|
| 需求重复追问率 | 已有明确有效字段却再次要求相同字段的提问/全部字段提问 | 开发用例覆盖，未统计真实样本 |
| 转写修改率 | 用户修改的最终转写/可编辑的最终转写 | 需真实STT及编辑事件扩展 |
| 打断成功率与延迟 | 有效打断后旧音频停止/有效打断数；从打断事件到停止音频 | 合成事件验证逻辑，未量真实音频 |
| 需求纠正率 | 被用户修订的提取字段/已提交提取字段 | revision可追溯；不是自动准确率 |
| 任务完成率 | 用户明确确认完成任务/有结果观察的任务，并单列未确认 | 仅演示中的自报结果；非商户回执 |
| 五人门槛完整性 | 满足5个不同有权账号、同版本、有效回归、无否决的发布/全部发布 | 服务端强制及程序/浏览器测试 |
| 变更后失效率 | 发布后相关bad case/该版本相关任务 | 真实试点待采集，不能把测试通过当改善 |
| 成本 | STT+模型+TTS+人工成本/完成任务 | 仅模型接口实际usage累计；没有账单或预算余额 |

反馈、批准及发布的数据保存在data/runtime，不加入公共仓库。审核记录中的账号不证明自然人独立性。对话默认不写数据库，勾选记忆后仅浏览器保存有限偏好。合成测试与实际模型/真人试点必须分开报。

上线试验建议：预先固定失败分类和任务分母，准备未用于开发的匿名问法，第二标注人复核；按会话版本对照，报告样本量与不确定性。不能为了减少转人工而让旅客停留在不可执行的自助流程中。
