# Visit China AI｜可用于简历的项目段

个人产品项目，产品与运营设计，AI辅助实现。应用层迭代，不是模型权重训练。

- **场景与交互：** 面向北京、上海、广州、深圳和香港的入境服务，建立城市与渠道边界及分层覆盖；统一语音、文字和点选上下文，围绕地点误触发任务、多轮纠正和低电量反馈迭代分流。
- **知识与回答：** 在5,000个官方URL索引基础上，补充版本绑定的标准KB快路径；有效条目命中时免模型生成，未命中继续RAG，结合原问保留、改写约束、BM25／TF-IDF与RRF融合，以及来源时效与适用范围检查。
- **运营闭环：** 关联未解决反馈、可选脱敏上下文和执行轨迹，支持问题归因、资料／技能候选、回放验收及人工发布／回滚；区分KB直出、检索有结果、用户解决与平台外跳指标。
- **测试与交付：** 保留2万条合成历史回归并新增多城市、KB失效、查询约束和候选校验用例；通过实际测试记录说明修改与局限，不以离线通过率代替真人语音或业务成效。

五城指城市识别、资料适用范围和精选入口；上海工具覆盖最深，其他城市并非同等全量地图、商户或库存。每个数量和测试成绩须以对应提交验收记录为准。
