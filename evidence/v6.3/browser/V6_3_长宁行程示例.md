# 长宁：愚园路—中山公园—苏河华政步道

按一个相邻街区组织慢游；愚园路和豫园是不同地点。

- 时间为可调整的行程建议，不是开馆时间、实时交通预测或已预约时段。
- 出发前核对开放、预约、天气与通行；餐饮和酒店不含实时房态、餐位、价格。

## 第 1 天 · 长宁街区

1. **09:00–10:00 愚园路历史街区**
   长宁区愚园路（江苏路至定西路段） — 从江苏路一侧开始，沿街看历史建筑与街区生活；不要把愚园路当作豫园景区。

2. **10:30–11:30 愚园公共市集**
   愚园路1088弄片区 — 区政府报道列出过乐喜、宜小蘭、Onita等就餐候选，按现场营业和饮食需要选择。

3. **12:15–13:15 中山公园**
   长宁区中山公园，万航渡路一侧可衔接华政步道 — 百年公园休息与散步，之后可前往相邻河岸步道。

4. **13:45–14:45 苏州河华政步道**
   万航渡路与华阳路交叉口等公开入口 — 沿公共河岸看历史校园建筑，教学区按现场开放范围参观。
